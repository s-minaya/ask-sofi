# Ask Sofi

Aplicación mínima para validar la base del proyecto.

## Requisitos

- Node.js 24
- npm

## Instalación y uso

```bash
# Clonar repositorio
git clone <repo-url>
cd ask-sofi

# Instalar dependencias
npm ci

# Desarrollo
npm run dev

# Verificación
npm run lint
npm run format:check
npm run typecheck
npm run test
npm run build
```
